## Agent skills

### Issue tracker

Work items are tracked as local markdown files under `local-file/tasks/`. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context layout — one `GLOSSARY.md` at the repo root with ADRs under `docs/adr/`. See `docs/agents/domain.md`.

### Local files

A path missing from `git status`, or a commit the user asked for, may be a beyond-local-file projection. See `docs/agents/blf.md`.
